Comment ça marche

  1. Cliquez sur Caméra et autorisez l'accès. Placez une main bien visible, à 40–80 cm, avec un bon éclairage.
  2. Formez une lettre et gardez-la immobile un court instant : la barre « Validation » se remplit, puis la lettre s'ajoute au mot.
  3. Changez de forme pour la lettre suivante. Pour une lettre double (LL, SS…), décalez la main sur le côté, ou baissez-la un instant et refaites la lettre.
  4. Espace : sortez la main de l'image 1,5 s, ou cliquez sur « Espace », ou appuyez sur la barre d'espace.
  5. Une main ouverte (cinq doigts tendus) n'écrit rien : pratique pour faire une pause entre deux lettres.
  6. J et Z sont des lettres en mouvement : formez la main puis dessinez la lettre dans l'air (sur une image fixe, elles sont reconnues à leur pose).

Bon à savoir

  • Confidentialité : tout le calcul se fait dans votre navigateur. Seuls le programme de détection et son modèle sont téléchargés (une fois) depuis un CDN ; aucune image ni donnée n'est envoyée.
  • Lettre mal reconnue ? Chaque personne signe un peu différemment. Dans « Réapprenez-la », enregistrez votre main 3 secondes : la lettre est aussitôt corrigée.
  • Mode test : chargez une vidéo (mp4) ou des images ; les lettres s'écrivent comme avec la caméra. Une image nommée A.jpg ou mot_B.png est comparée à la lettre attendue.
  • Les dessins ci-dessous montrent la main telle que vous la voyez face à la personne qui signe (main droite).

Il existe de petites variantes de l'alphabet selon les régions et les personnes. Les lettres proches (A / S / E, F / T, U / R / V, M / N) demandent une main bien visible ; n'hésitez pas à les réapprendre avec votre main.
